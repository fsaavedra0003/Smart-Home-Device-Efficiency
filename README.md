# Smart-Home-Device-Efficiency 🌍💡

## Overview 📊

This project is designed to optimize the energy efficiency of various smart home devices by leveraging real-time data and monitoring tools. By analyzing device usage patterns, energy consumption, and smart home efficiency, we aim to reduce energy consumption while maintaining comfort, security, and functionality in a modern smart home environment. 🏠🔌

The system uses a dataset that contains information about various smart home devices, including energy consumption, usage hours, and other relevant metrics. With this data, the project aims to offer insights into how users can optimize their device usage for energy savings. ⚡💡

## Features ✨

- **Monitor Smart Devices** 📱: Track the status and energy consumption of multiple smart devices.
- **Efficiency Calculation** 📈: Analyze energy efficiency and provide suggestions for optimization based on device usage.
- **Smart Alerts** ⚠️: Set thresholds for automatic power-saving modes or notifications when devices are consuming too much energy.
- **Device Data Management** 🗂️: Manage device data by toggling device efficiency status and saving the updated data back to a CSV file.

## Dataset 📋

The dataset used in this project is sourced from **Kaggle** and contains data from multiple smart home devices. It includes important parameters like:

- **Device Type** 🖥️: Type of smart device (e.g., Smart Speaker, Camera, Security System).
- **Usage Hours per Day** ⏰: Average daily usage of each device.
- **Energy Consumption** ⚡: Energy consumption of the device in kWh.
- **User Preferences** 🛠️: Whether the user prefers the device to be on or off.
- **Malfunction Incidents** 🔧: Number of times the device has had malfunction incidents.
- **Device Age** 📅: Age of the device in months.
- **Smart Home Efficiency** ✅: A binary indicator of whether the device is considered efficient.

With the growing prevalence of **Internet of Things (IoT)** devices in smart homes, this project aims to provide insights into making these devices more energy-efficient and cost-effective. As IoT platforms become more diverse, integrating and optimizing devices for efficiency has become a key area of research and application. 🌐🔌
